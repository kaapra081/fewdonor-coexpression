\paragraph{A real-cell null with exact truth (plan frozen before the run).} To test the leak on real cells with known truth, we pooled the nuclei of each supertype and randomly reassigned them to pseudo-donors with the real donors' cell numbers (5 reassignments per supertype; \texttt{prereg/FIX\_PREREG.md}). The pseudo-donors are exchangeable draws from one population, so the between-donor covariance is exactly zero for every pair while every real within-cell program is kept; every call is a false discovery. In Micro-PVM\_1 (79 pseudo-donors, median 15 nuclei) pseudobulk made 3{,}714 false discoveries per reassignment (range 2{,}976--4{,}601) and in Micro-PVM\_3 2{,}714 (1{,}630--3{,}669); LCP made no calls in any reassignment of either supertype (mean 0 and 0). Pseudobulk's per-pair type-I error at $\alpha=0.05$ was 0.18 and 0.17, and 0.67 and 0.61 for the 1\% most within-correlated pairs. LCP's per-pair type-I error was 0.081 and 0.061 (0.092 and 0.099 for the top 1\%), so by the frozen criterion LCP does not fully hold this null at the single-pair level, although none of that excess reaches the multiple-testing threshold. One caveat: pooling turns the real donors' between-donor covariance into within-pseudo-donor covariance, so this null's within-donor structure is somewhat stronger than real donors' (median absolute within-donor correlation 0.086 versus 0.074 in Micro-PVM\_1), and 0.31 of pseudobulk's false calls are pairs that LCP calls between real donors (base rate 0.10).
